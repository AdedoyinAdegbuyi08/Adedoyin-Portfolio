# Adedoyin Adegbuyi | Portfolio

A responsive personal portfolio showcasing my work as a front-end developer and product designer.

**Live demo:** https://adedoyinadegbuyi08.github.io/Adedoyin-Portfolio/

## Features
- Home, About, Projects and Contact pages
- Responsive layout with a hamburger menu at 768px and below
- Contact form with validation
- Project showcase featuring RouteNG

## Tech stack 
HTML5, CSS3, JavaScript, Git and GitHub Pages

## Run locally
1. Clone the repo: `git clone https://github.com/adedoyinadegbuyi08/Adedoyin-Portfolio.git`
2. Open the folder in VS code
3. Right-click `index.html` and choose **Open with Live Server**
